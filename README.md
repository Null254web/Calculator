# Calculator

A responsive calculator built using HTML, CSS, and JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear button
- Responsive design

## Technologies

- HTML
- CSS
- JavaScript

## Installation

Clone the repository:

```bash
git clone https://github.com/omindeagrey204-eng/Calculator.git
```

Open `calculator.html` in your browser.
